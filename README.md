# ons-for-all

中國醫藥大學北港附設醫院臨床營養科的「院內營養品臨床評估與動態試算系統」。此專案是一個純前端單頁工具，協助依據病人基本資料、照護場景、器官機能、灌食途徑與院內營養品清單，快速估算營養需求、配方供應量與醫令紀錄文字。

目前專案已部署於 GitHub Pages：

<https://yht5582-source.github.io/ons-for-all/>

## 專案內容

此 repository 目前包含：

- `index.html`：主要應用程式，內含 HTML、CSS 與 JavaScript。
- `README.md`：專案說明文件。
- `tests.cjs`：計算引擎測試。

無建置流程與後端，可直接以瀏覽器開啟 `index.html` 使用；計算引擎測試以 `node tests.cjs` 執行。

## 主要功能

- 輸入基本生理資料：性別、年齡、身高、實際體重。
- 選擇照護場景與臨床狀態：
  - 門診 / 社區
  - 一般病房
  - ICU / Critical Care
  - 一般內科、外科手術 / 創傷、敗血症、燒燙傷、腫瘤照護
- 選擇呼吸器與血糖代謝狀態：
  - 未使用呼吸器
  - 使用呼吸器無 CO2 滯留
  - 使用呼吸器且有 CO2 滯留 / 高碳酸血症
  - 正常血糖、糖尿病 / 糖耐量異常、應激性高血糖
- 選擇器官機能與灌食途徑：
  - 腎功能正常
  - CKD Stage 1-4 未透析
  - HD、PD、CRRT
  - 經口進食、鼻胃管灌食、PEG / J-tube
  - 正常腸胃道、消化吸收不良 / 短腸症、腹瀉 / 腸黏膜發炎
  - 一般水分需求或嚴格限水
- 自動計算：
  - 理想體重（IBW）
  - BMI 與體位分類
  - 每日目標熱量範圍
  - 每日目標蛋白質範圍
  - 每日建議水需求量
- 根據條件顯示院內營養品推薦與醫令建議。
- 選擇院內主營養品，並依每日罐數試算熱量與蛋白質供應量。
- 可加入蛋白質模組或熱量模組，估算總熱量、總蛋白質與達成率。
- 產生「臨床評估摘要與醫令紀錄」文字，並提供一鍵複製。

## 計算邏輯摘要（v2.0）

計算引擎 `ONS` 位於 `index.html` 的 `/*ENGINE-START*/ … /*ENGINE-END*/` 區塊，測試：`node tests.cjs`。

### 理想體重、BMI 與計算體重

- 男性 IBW：`(身高 - 80) × 0.7`；女性 IBW：`(身高 - 70) × 0.6`
- BMI 分級依國健署：18.5 / 24 / 27
- 計算體重（可切換）：自動＝實際體重 < IBW 用實際體重；> 120% IBW 用調整體重 `IBW + 0.25 × (實際 − IBW)`；其餘用 IBW
- 身高 100–230 cm、體重 20–250 kg、年齡 18–120 歲以外會提示錯誤

### 熱量需求

- 一般、ICU、敗血症：`25–30 kcal/kg`（ASPEN 2016；ICU 急性期另提示漸進給予）
- 大面積燒燙傷：`35–40 kcal/kg`（建議以 IC 校正）
- ICU 且 BMI 30–50：`11–14 kcal/kg 實際體重`；BMI > 50：`22–25 kcal/kg IBW`

### 蛋白質需求（取所有適用狀況中最高的範圍）

- 一般 `1.0–1.2`、腫瘤 `1.0–1.5`、外科/敗血症 `1.2–1.5`、ICU/呼吸器 `1.2–2.0`、燒燙傷 `1.5–2.0` g/kg
- CKD 3–5 未透析且非急性期：`0.6–0.8 g/kg`（ICU、外科/創傷、敗血症、燒燙傷或使用呼吸器時不限制）
- HD / PD：`1.0–1.2 g/kg`（KDOQI 2020）；CRRT：`1.5–2.5 g/kg`
- ICU 肥胖：BMI 30–40 `2.0 g/kg IBW`、≥ 40 `2.0–2.5 g/kg IBW`

### 水分需求

- 無限制：`30 mL/kg × 計算體重`；嚴格限水：`1 mL/kcal`（熱量下限）；HD/PD：前日尿量 + 500–1000 mL
- 管灌時另估配方含水量與需補充的自由水

### 配方試算

主營養品份數 + 蛋白質模組 + 熱量模組，模組的熱量與蛋白質都會計入。達成率以目標範圍中位數計算，並標示低於/達到/高於目標範圍。

## 院內營養品資料

品項資料在引擎內的 `PRODUCTS` 與 `MODULES` 陣列，數值與 `ons-choice-for-all` 已查證的廠商標示同步（2026-10）。推薦清單會依病況提示，並在所選主營養品與病況不符時（如 CKD 未透析選高蛋白配方、透析選低蛋白配方、基速得當主營養）顯示警示。

## 教學分頁（v2.1）

頁面上方分頁：試算工具、示範病例（`#cases`，6 例）、考題（`#quiz`，基礎 10＋高階 10）、心智圖（`#map`）。

- 內容在 `index.html` 的 `/*CASES-START*/`、`/*QUIZ-START*/`、`/*MAP-START*/` 區塊；病例表格由引擎即時算出，「帶入試算工具」可把病例載入工具。
- 考題選項順序固定、A–D 各 5 題，不儲存作答。
- `tests.cjs` 核對病例 `expect` 與考題答案；修改公式或品項後，敘述文字中的數字要一併更新。

## 維護注意事項

- 此專案目前是單一靜態 HTML 檔，樣式與計算邏輯都集中在 `index.html`。
- 若修改院內品項，需同步確認品名、醫令碼、熱量、蛋白質與推薦文字是否一致。
- 若修改臨床公式，建議由醫師與營養師共同核對後再發布。
- 若品項數量增加，可考慮日後將營養品資料拆成獨立資料檔，降低維護成本。

## 臨床使用聲明

本工具用於院內營養評估、配方試算與醫令文字整理的輔助。試算結果不能取代臨床判斷，使用時仍需整合病人診斷、檢驗資料、腎功能、電解質、水分限制、血糖控制、腸胃耐受性、吞嚥功能與營養師評估。
